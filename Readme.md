# Reporting System

A comprehensive and user-friendly reporting system built primarily with PHP, CSS, and JavaScript. This project is designed to streamline the process of creating, managing, and reviewing reports, making it an ideal solution for organizations needing efficient reporting workflows.

## Features

- **User Authentication**: Secure login and role-based access control.
- **Dynamic Report Generation**: Create and customize reports with ease.
- **Responsive UI**: Mobile-friendly design with modern CSS styling.
- **Interactive Dashboards**: Visualize data through charts and tables.
- **Export Options**: Download reports in multiple formats (PDF, CSV, etc.).
- **Notifications**: Stay updated on report statuses and comments.

## Tech Stack

- **Backend**: PHP
- **Frontend**: HTML, CSS, JavaScript

## Getting Started

### Prerequisites

- PHP ^7.4 or higher
- Composer
- Web server (Apache, Nginx, etc.)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/olyadboka/Reporting-system.git
   cd Reporting-system
   ```

2. **Install dependencies**
   ```bash
   composer install
   ```

3. **Configure environment**
   - Copy `.env.example` to `.env` and update configuration as needed.

4. **Set up database**
   - Import the SQL schema from the `/database` directory.
   - Update database credentials in your `.env` file.

5. **Run the application**
   - Start your web server and access the app via `http://localhost/Reporting-system`.

## Usage

- Register or log in with your credentials.
- Create new reports using the intuitive form interface.
- Manage, edit, or delete existing reports from the dashboard.
- Export reports as needed for sharing or archival purposes.
